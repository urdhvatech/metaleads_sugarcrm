Overview

Perform an intelligence summary inference operation on a specified module and record.

Summary

This endpoint triggers an intelligence summarization inference process for a specific record and module. If a translation or result for the current language and hash already exists, it is reused.

Request Arguments

Name Type Description Required
module string The name of the module (e.g., Opportunities, Accounts) True
recordId string ID of the record for which the inference is triggered True

Request Example

POST /rest/v11_27/Opportunities/{recordId}/intelligence/summary/infer
{
    "module": "Opportunities",
    "recordId": "abc123"
}

Response Example

{
    "evalId": "abc123-eval-id",
    "status": "completed",
    "summary": "Here is the previously saved summary for this record...",
    "dateModified": "2025-06-26T08:12:00Z"
}

Error Responses

  • 401 Unauthorized – Backend is not configured properly
  • 402 Payment Required – Token limit exceeded
  • 403 Forbidden – User does not have access to summarization
  • 500 Server Error – Unexpected failure
