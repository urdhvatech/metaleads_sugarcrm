Overview

Retrieves historical delta changes for a module based on a timestamp and list of records.

Summary

This endpoint returns field-level change data for a given set of records in a module, comparing their current state to the state at the specified deltaDate. It is used to track and return only the fields that have changed since the provided timestamp.

Request Arguments

Name Type Description Required
module String The module name for which to retrieve delta changes (e.g., Opportunities). True
recordIds Array Array of record IDs from the given module to evaluate for delta changes. True
deltaDate String A timestamp (ISO 8601) (e.g., 2024-01-01T00:00:00Z) representing the point in time to compare the current record state against. True

Response

Returns an array of changed fields for each record ID, including old and new values as decorated by the delta decorator.
