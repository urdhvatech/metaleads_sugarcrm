Overview

Retrieves the current usage token information from the vendor.

Summary

This endpoint fetches the current token usage count used for summarization or generative AI interactions. It is useful for monitoring consumption and quota usage.

Request Arguments

This endpoint does not require any request parameters.

Request Example

GET /rest/v11/service/intelligence/usage/token

Response Example

{
  "data": 32,
  "error": false
}

Response Fields

Field Type Description
data integer | null The current token usage count. If retrieval fails, this will be null.
error boolean Indicates whether an error occurred while retrieving the token usage.

Error Handling

  • 401 Unauthorized: Returned when the user lacks access to SummarizationGai data (SugarApiExceptionNotAuthorized).
  • 200 OK with error=true: Returned when an exception occurs during retrieval. data will be null and error will be true.
