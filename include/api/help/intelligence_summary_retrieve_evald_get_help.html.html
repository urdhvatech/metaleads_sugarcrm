Overview

Retrieves the result of an intelligence summarization using evalId.

Request Arguments

Name Type Description Required
module string The module to which the summary relates Yes
recordId string The ID of the related record Yes
evalId string The evaluation ID associated with the summarization Yes

Request Example

GET /rest/v11/Accounts/abc123/intelligence/summary/retrieve/xyz-eval-id

Response Examples

Completed Summary

{
  "evalId": "xyz-eval-id",
  "status": "completed",
  "data": {
    "id": "abc123",
    "summary": "AI-generated summary content...",
    "language": "en_us",
    "date_modified": "2025-07-01T12:00:00Z"
  },
  "currentLanguage": "en_us"
}

Processing Status

{
  "evalId": "xyz-eval-id",
  "usecaseType": "gai_summary",
  "status": "processing"
}

Error Responses

  • 401 Unauthorized – User lacks access or GAI backend is not configured
  • 404 Not Found – Eval ID was not found
  • 422 Unprocessable Entity – Empty or invalid summary response
  • 500 Server Error – Internal server error with message
