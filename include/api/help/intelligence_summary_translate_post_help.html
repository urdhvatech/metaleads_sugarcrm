Overview

Retrieves or creates a translated summary for a specific record and language.

Summary

This endpoint retrieves a translated summary of a record's data in the specified language. If a translation already exists and is up to date, it is returned immediately. If it does not exist or is outdated, a new translation is generated asynchronously. The system ensures that only completed summaries can be translated.

Request Arguments

Name Type Description Required
module string Name of the module True
recordId string The ID of the record to fetch or translate the summary for True
language string Language code of the desired translation True

Request Example

POST /rest/v11/Accounts/abc123/intelligence/summary/translate
{
  "module": "Accounts",
  "recordId": "abc123",
  "language": "fr_FR"
}

Response Example (Translated Summary Exists)

{
  "status": "completed",
  "currentLanguage": "fr_FR",
  "summaryLanguage": "fr_FR",
  "summary": "Résumé existant du contenu",
  "lastSyncDate": "2025-06-30T12:00:00Z",
  "neededFollowup": {
    "Needed Follow-ups": [
      {
        "moduleName": "Calls",
        "objectId": "12345678-aaaa-bbbb-cccc-987654321000",
        "name": "Appel de découverte",
        "followUp": "Programmer un appel de suivi pour confirmer les prochaines étapes.",
        "icon": "sicon-call-lg",
        "iconColor": "label-module-color-blue",
        "link": "#Calls/12345678-aaaa-bbbb-cccc-987654321000"
      }
    ]
  }
}

Response Example (Summary Not Yet Available)

{
  "status": "not_found"
}

Error Handling

  • 401 Unauthorized: Returned if the user does not have permission to access summary data (throws SugarApiExceptionNotAuthorized).
  • 404 Not Found: Returned when the original summary has not yet been completed or linked (status: not_found).
  • 500 Internal Server Error: For unexpected exceptions (e.g., translation failure or ingestion issues).
