Overview

Fetches the last completed summarization result saved for a given record.

Request Arguments

Name Type Description Required
module string The module name Yes
recordId string The ID of the record Yes
language string (Optional) The preferred language for the summary No

Request Example

GET /rest/v11/Accounts/abc123/intelligence/summary/retrieve

Response Example

{
  "summary": "X-Sell Holdings has shown significant engagement this quarter, indicating positive growth.",
  "dateModified": "2025-06-15T10:42:00+00:00"
}

Error Responses

  • 401 Unauthorized – User lacks access
  • 404 Not Found – No saved summary found for the given record
  • 500 Server Error – Internal server error with message
