Meta Leads setup guide

Create a Meta app with the Lead Ads use case, then connect it to SuiteCRM. Products are added automatically from the use case — do not add them separately.

Before you start

  • SuiteCRM with Meta Leads installed and licensed
  • A SuiteCRM admin login
  • A Facebook user who can advertise on the Pages (including Pages in a Business Portfolio)
  • A public HTTPS SuiteCRM URL. Localhost will not receive Meta webhooks.
Replace https://your-crm.example.com with your real SuiteCRM site URL. No trailing slash. The redirect URI and webhook URL must match SuiteCRM character-for-character (https, www, path).

URLs used by SuiteCRM

SuiteCRM field Value to paste in Meta
OAuth Redirect URI https://your-crm.example.com/index.php?entryPoint=ut_sm_oauth_handler
Callback URL (Webhook URL) https://your-crm.example.com/index.php?entryPoint=ut_sm_inbound
Verify Token Any secret you choose, for example SuiteCRM_MetaLeads_2026. Letters, numbers, . _ - only (3–255 characters). Must be identical in Meta and SuiteCRM.

Step 1 — Create the Meta app

  1. Open https://developers.facebook.com/apps/
  2. Click Create app.
  3. When Meta asks how the app will be used, select only this use case:
    Capture & manage ad leads with Marketing API
  4. Enter an app name (for example Your Company CRM Leads) and a contact email.
  5. Connect a Business Portfolio if asked.
  6. Create the app.

Use cases — select vs do not select

Use case Why
Select Capture & manage ad leads with Marketing API This is the Lead Ads + CRM flow. Meta adds Facebook Login for Business and Webhooks automatically.
Do not select Authenticate and request data from users with Facebook Login Consumer login. SuiteCRM users do not sign in with Facebook.
Do not select Manage everything on your Page Page posting and moderation. Extra permissions you cannot easily remove.
Do not select Create & manage ads with Marketing API Creating campaigns. This CRM only reads leads.
Do not select Measure ad performance data with Marketing API Ad insights. Not used.

After you select the Lead Ads use case, Meta automatically adds these products. Do not search for Add product to add them again:

  • Facebook Login for Business
  • Webhooks

Step 2 — Customize permissions

  1. In the app dashboard open Use cases.
  2. Open Capture & manage ad leads with Marketing API.
  3. Click Customize.

Required by Meta (grey / cannot remove — leave them)

These are required for this use case. business_management is required so Pages in a Business Portfolio appear in SuiteCRM.

  • leads_retrieval
  • pages_manage_ads
  • pages_read_engagement
  • pages_show_list
  • business_management
  • ads_management
  • ads_read
  • public_profile
  • Ads Management Standard Access
The trash icon next to business_management is grey because this use case requires it. That is expected. Do not add a second use case just to get this permission, and do not try to delete it.

Add this optional permission (required for SuiteCRM webhooks)

  1. Find pages_manage_metadata.
  2. Click Add.

SuiteCRM uses this to subscribe each Page to leadgen so new leads are pushed in real time.

Do not add

  • email
  • Business Asset User Profile Access
  • catalog_management
  • Page posting, messaging, or Instagram content permissions

Step 3 — Facebook Login for Business (OAuth redirect)

  1. Open Facebook Login for Business → Settings (or the Login section under the Lead Ads use case).
  2. Turn on Client OAuth login and Web OAuth login if those toggles are shown.
  3. Under Valid OAuth Redirect URIs paste exactly:
https://your-crm.example.com/index.php?entryPoint=ut_sm_oauth_handler
  1. Click Check URI if shown, then Save.
  2. In SuiteCRM go to Admin → Meta Leads and put the same URL in OAuth Redirect URI.
If you use Login Configurations: token type = User access token (not system user). Request Pages (and Instagram only if you want linked IG accounts listed). Include the Lead Ads permissions above plus pages_manage_metadata.

Step 4 — Webhooks (Page leadgen)

Configure this from the Lead Ads use case → Webhooks, or the left menu Webhooks.

  1. In SuiteCRM Admin → Meta Leads, enter the Callback URL and Verify Token and click Save Settings first. Meta cannot verify the webhook until SuiteCRM already has these values.
  2. In Meta, set object / product to Page (not Instagram, not User, not Ad Account).
  3. Callback URL:
https://your-crm.example.com/index.php?entryPoint=ut_sm_inbound
  1. Verify token: the same secret saved in SuiteCRM.
  2. Click verify. Meta sends a GET request; SuiteCRM must return the challenge.
  3. Subscribe to field leadgen only. Do not subscribe to feed, messages, or name.

Step 5 — Copy App ID and App Secret into SuiteCRM

  1. In Meta open App settings → Basic.
  2. Copy App ID and App Secret.
  3. Set a Privacy Policy URL (required before the app can go Live / Publish).
  4. In SuiteCRM Admin → Meta Leads paste App ID, App Secret, OAuth Redirect URI, Callback URL, and Verify Token.
  5. Click Save Settings.

Step 6 — Authorize and connect Pages

  1. On the same SuiteCRM screen click Authorize with Facebook.
  2. Log in as a Facebook user who can advertise on the Pages.
  3. Grant the Lead Ads permissions, including business management.
  4. Allow every Page you want in the CRM, including Business Portfolio Pages.
  5. Confirm SuiteCRM shows Connected and lists Pages under Connected Accounts.
SuiteCRM requests these scopes on Authorize: pages_show_list, leads_retrieval, pages_read_engagement, pages_manage_metadata, pages_manage_ads, business_management. Meta also requires ads_management and ads_read for this use case; leave those on the app even though the CRM does not create ads.

Step 7 — Enable forms

  1. Next to each Page click Configure.
  2. Click Refresh Forms.
  3. Enable the Lead Ads forms that should import into SuiteCRM.
  4. Map custom questions to Lead fields if needed. Email and name usually map automatically.
  5. Click Save Configuration.

Step 8 — Send a test lead

  1. Open https://developers.facebook.com/tools/lead-ads-testing
  2. Select this app, the Page, and an enabled form.
  3. Create a test lead.
  4. In SuiteCRM open Leads and confirm the record was created.

SuiteCRM cron should be running so token refresh and missed-lead reconciliation can run.

Step 9 — Go Live (other people’s Pages)

Until App Review is approved, only app Admins, Developers, and Testers can connect Pages.

  1. Complete Business Verification on the Meta Business Portfolio.
  2. Submit App Review for the Lead Ads use case permissions (including pages_manage_metadata).
  3. In the review notes, explain how to log into SuiteCRM, open Admin → Meta Leads, click Authorize with Facebook, confirm Pages appear (including Business Portfolio Pages), enable a form, and create a test lead.
  4. After approval, Publish the app.
  5. In SuiteCRM click Disconnect, then Authorize with Facebook again.

Checklist

In Meta

  • Use case: Capture & manage ad leads with Marketing API only
  • Added optional permission: pages_manage_metadata
  • Did not add email or extra use cases
  • OAuth redirect URI matches SuiteCRM exactly
  • Webhooks → Page → leadgen
  • Callback URL and verify token match SuiteCRM
  • Privacy policy URL set

In SuiteCRM

  • Admin → Meta Leads → credentials saved
  • Authorize with Facebook completed
  • Pages listed under Connected Accounts
  • Forms enabled on Configure
  • Test lead created a SuiteCRM Lead
