Overview

Dropdown Editor

Summary

Get details of dropdown that can be changed.

Request Arguments

Name Type Description Required
dropdownName string The dropdown name True
language string The dropdown language False
comparisonLanguage string The dropdown comparison language False
role string The role for view selection False

Response Arguments

Value Label Description
label string Item name
value string Item value
role boolean Is this item included in the role?
classification object Classification value
comparisonLabel string Comparison label value
style array Style value

Request Example

{
    "dropdownName":"sales_stage_dom",
    "language":"fr_FR",
    "comparisonLanguage":"en_us",
    "role":"813c0628-0a40-11f0-9d19-0242ac120002"
}
