Overview

Dropdown Editor Update

Summary

Set details of dropdown

Request Arguments

Name Type Description Required
dropdownName string The dropdown name True
language string The dropdown language True
comparisonLanguage string The dropdown comparison language True
role string The role for view selection True
formatting boolean Is formatting enabled? True

Response Arguments

Name Type Description
success boolean True if the request was successful
