Overview

Dropdown Editor

Summary

Restore the dropdown list to its default data

Request Arguments

Name Type Description Required
dropdownName string The dropdown name True

Response Arguments

Name Type Description
success bolean True if the request was successful

Request Example

{
    "dropdownName":"sales_stage_dom",
}

Response Example

{
    'success': true
}
