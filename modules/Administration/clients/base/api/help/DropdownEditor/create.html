Overview

Dropdown Editor

Summary

Create Dropdown DOM issue as a php-file in customer storage directory.

Request Arguments

Name Type Description Required
dropdown_name string New dropdown dom name True
language string Selected language False
items array Set of key-label pairs False
formatting boolean Is formatting enabled? True

Response Arguments

Value Label Description
Empty array
